# Bus Captain SG — Driver Seat Edition (V3)

A browser-based first-person Singapore bus-driving game for children.

## V3 cockpit changes
- True right-hand-drive bus-captain seating geometry based on the supplied reference image.
- Large multi-turn steering wheel directly in front of the driver.
- Drag/touch the steering wheel through up to 450° left or right.
- Instrument binnacle behind the wheel with speed, route and warning lamps.
- Left-side fare/ticket console and passenger-operation switches.
- Right-side vehicle controls for indicators, wipers and lights.
- Physical brake and accelerator pedals in the driver footwell.
- Left/right exterior mirrors plus interior mirror.
- Wide multi-pane windscreen with cab pillars.
- Existing Singapore road, bus-stop, passenger, weather and scoring simulation retained.

## Controls
- Drag steering wheel: steer directly
- A / Left Arrow: turn wheel left
- D / Right Arrow: turn wheel right
- W / Up Arrow: accelerator
- S / Down Arrow: brake
- Q / E: left/right indicator
- Space: door open/close
- Double-click steering wheel: centre wheel

## Hosting
Upload the contents of this folder to the root of a GitHub repository and publish with GitHub Pages or Cloudflare Pages. `index.html` must remain at the repository root.

No API key is included in this prototype.
